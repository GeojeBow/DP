# NeoDir

Q-Dir처럼 한 창에서 폴더 여러 개를 나란히 다루는 파일 관리자입니다. 설치 없이 `NeoDir.exe` 하나만 복사해서 실행합니다 (관리자 권한, .NET 설치 모두 필요 없음).

## 받기

GitHub의 **Actions → NeoDir (Windows exe)** 에서 최근 실행을 열고 맨 아래 **Artifacts** 의 `NeoDir-win-x64` 를 받으면 zip 안에 `NeoDir.exe` 가 있습니다. `neodir-v0.1.0` 같은 태그를 올리면 Releases 에도 올라갑니다.

설정(레이아웃, 열린 탭, 즐겨찾기)은 exe 옆의 `NeoDir.settings.json` 에 저장됩니다. 그 폴더에 쓸 수 없으면 `%APPDATA%\NeoDir` 에 저장합니다. USB에 넣고 다니면 설정도 같이 따라갑니다.

## Q-Dir와 비교한 기능 계획

| 영역 | Q-Dir | NeoDir (지금) | 다음 단계 |
| --- | --- | --- | --- |
| 레이아웃 | 1~4분할, 여러 배치 | 1, 좌우 2, 위아래 2, 3, 4분할 · **세로 모니터용** 3단·4단·위1+아래2 · Ctrl+1~8 · 분할선 드래그 · **작업공간** 저장/불러오기 (Ctrl+Alt+1~9) | 작업공간마다 창 크기까지 저장 |
| 탭 | 패널마다 탭 | 패널마다 탭, 탭마다 뒤로/앞으로 기록, 휠 클릭 닫기 | 탭 끌어서 다른 패널로 옮기기, 탭 고정 |
| 주소창 | 경로 표시 | 클릭하는 경로 조각(breadcrumb), › 누르면 하위 폴더 목록, 직접 입력·%변수% | 입력 자동완성 |
| 찾기 | 없음(탐색기 검색) | **즉시 필터**: 띄어쓰기=모두 포함, `;`=또는, `*.pdf` 와일드카드 · 필터에서 Enter = **하위 폴더까지 검색** (결과에 위치 열) | 파일 내용 검색 |
| 색상 필터 | 확장자별 색 | 이미지·영상·문서·압축·코드·실행파일 색 구분 (설정 파일에서 변경) | 색상 규칙 편집 화면 |
| 즐겨찾기/빠른 링크 | 메뉴 | 사이드바: 즐겨찾기(끌어 놓기로 추가, 이름 바꾸기·순서), 빠른 이동(**OneDrive 개인·회사 자동 표시**), 드라이브 사용량 막대 | 즐겨찾기 그룹 |
| 파일 작업 | 탐색기 메뉴 | 복사/잘라내기/붙여넣기(탐색기와 클립보드 호환), 끌어 놓기(같은 드라이브=이동), 휴지통 삭제, 이름 바꾸기, 새 폴더/텍스트 문서, 경로 복사, 터미널·탐색기에서 열기, 속성 · **Windows 기본 메뉴** (Shift+우클릭: 압축, 보내기, 새로 만들기) · **미리보기 패널** (Ctrl+P: 이미지, 텍스트, PDF·영상 썸네일) · OneDrive 온라인 전용 파일 ☁ 표시 | 일괄 이름 바꾸기, 폴더 크기 계산 |
| 패널 연동 | 일부 | Shift+Enter 옆 패널에서 열기, Ctrl+Shift+→ 지금 폴더를 옆 패널에도 | 두 패널 폴더 비교, 동시 스크롤 |
| 디자인 | 기본 Win32 | 다크 테마, 보라→하늘색 포인트, 둥근 패널, 활성 패널 강조 | 라이트 테마, 포인트 색 고르기 |
| 배포 | 휴대용 exe | 단일 exe (self-contained, 압축) | 자동 업데이트 확인 |

## 구조

| 경로 | 내용 |
| --- | --- |
| `src/NeoDir.Core` | 화면과 무관한 로직 (경로 조각, 필터, 색상 규칙, 이름 중복 처리, 설정 저장). 어느 OS에서나 테스트됩니다. |
| `src/NeoDir` | WPF 앱 (.NET 8). `MainWindow` = 제목 표시줄·사이드바·레이아웃, `FolderPane` = 패널 하나 (탭·주소창·목록) |
| `tests/NeoDir.Core.Tests` | xUnit 테스트 |

## 직접 빌드 (Windows)

```powershell
cd apps/neodir
dotnet test tests/NeoDir.Core.Tests
dotnet publish src/NeoDir/NeoDir.csproj -c Release -o publish   # publish/NeoDir.exe
```

## 회사 PC에서 막힐 때

- 처음 실행 시 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요 (서명되지 않은 exe라서 뜹니다).
- 회사 보안 정책(AppLocker 등)이 허용 목록에 없는 exe를 막는 경우엔 실행되지 않을 수 있습니다. 이건 프로그램이 아니라 회사 정책 문제라 IT 부서 허용이 필요합니다.
