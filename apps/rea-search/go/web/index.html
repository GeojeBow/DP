NTFS 드라이브는 자동으로 색인되고 바뀐 내용이 실시간으로 반영됩니다. 네트워크 폴더나 외장 드라이브처럼 그 밖의 폴더는 여기에 추가하면 정해진 주기마다 다시 훑어 색인합니다. 연결이 끊겨도 마지막 색인으로 계속 검색됩니다.

내용을 자주 검색하는 폴더를 추가하면 문서의 글자를 미리 색인해 둡니다. 수십만 개 파일도 몇 초 안에 찾고, 바뀐 파일만 다시 읽습니다. 색인하지 않은 폴더도 내용 검색은 되지만 검색할 때마다 파일을 직접 읽어 느립니다.

읽는 형식: 텍스트·코드 파일(UTF-8, UTF-16, EUC-KR), Word(docx), Excel(xlsx), PowerPoint(pptx), 한글(hwpx), OpenDocument. PDF와 예전 hwp·doc·xls 형식은 아직 읽지 못합니다.

Ctrl+F이름 검색창으로 Ctrl+Shift+F내용 검색 열기/닫기 ↑ ↓결과 이동 (Shift로 여러 개 선택) Enter열기 Ctrl+Enter폴더에서 보기 Space미리보기 열기/닫기 Ctrl+C선택한 항목의 전체 경로 복사 Ctrl+A불러온 결과 모두 선택 Esc메뉴 닫기, 검색어 지우기

창을 닫아도 프로그램은 백그라운드에서 색인을 최신으로 유지합니다. 실행 파일을 다시 실행하면 바로 창이 열립니다.
