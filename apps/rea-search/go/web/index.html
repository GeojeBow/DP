설정

NTFS 드라이브는 자동으로 색인되고 바뀐 내용이 실시간으로 반영됩니다. 네트워크 폴더나 외장 드라이브처럼 그 밖의 폴더는 여기에 추가하면 정해진 주기마다 다시 훑어 색인합니다. 연결이 끊겨도 마지막 색인으로 계속 검색됩니다.

내용을 자주 검색하는 폴더를 추가하면 문서의 글자를 미리 색인해 둡니다. 수십만 개 파일도 몇 초 안에 찾고, 바뀐 파일만 다시 읽습니다. 색인하지 않은 폴더도 내용 검색은 되지만 검색할 때마다 파일을 직접 읽어 느립니다.

읽는 형식: 텍스트·코드 파일(UTF-8, UTF-16, EUC-KR), 한글(hwp, hwpx), Word(doc, docx), Excel(xls, xlsx), PowerPoint(ppt, pptx), PDF, OpenDocument. 암호가 걸린 문서와 스캔한 이미지 PDF는 읽지 못하며, 색인 현황에서 목록을 볼 수 있습니다.

켤 때 바로 색인

처음 실행할 때는 저장된 색인이 없어 한 번은 색인합니다. NTFS 빠른 색인에서는 꺼진 동안 바뀐 파일만 따라잡습니다.

언제 다시 색인할지 정합니다. 주기(몇 시간마다)와 매일 정한 시각을 함께 쓸 수 있고, 언제든 바꿀 수 있습니다. 바꾸면 바로 저장되고 적용됩니다. 둘 다 끄면 "지금 색인"을 누를 때만 색인합니다.

빠른 색인 (관리자 권한)

이 프로그램은 아무것도 설치하지 않습니다. 관리자 권한은 드라이브의 파일 목록(NTFS)을 직접 읽어 수백만 개도 몇 초에 색인하고 바뀐 내용을 즉시 반영하는 데만 씁니다. 권한 없이도 모든 기능을 쓸 수 있고, 그때는 폴더를 하나씩 훑어서 색인합니다(처음 색인이 느리고, 바뀐 파일은 몇 분 뒤 반영).

검색창 옆에서 이름+내용이나 내용을 고르면 같은 조건으로 파일 안의 글자도 찾습니다: 회의 예산 모두, 계약 | 발주 하나라도, 회의 !취소 빼기, "분기 실적" 정확한 구문. ext: size: dm: file:, 경로(D:\자료\)는 어떤 파일을 읽을지 정하는 조건으로 쓰입니다. 예: 예산 !초안 ext:hwp;xlsx dm:2024 = 2024년에 고친 한글·엑셀 파일 중 내용에 '예산'이 있고 '초안'은 없는 파일. 대소문자(Aa)와 정규식(.*) 단추도 내용에 똑같이 적용됩니다.

창을 닫아도 프로그램은 백그라운드에서 색인을 최신으로 유지합니다. 실행 파일을 다시 실행하면 바로 창이 열립니다.
